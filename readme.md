# 🏠 House Price Predictor App

This project predicts house prices using a trained machine learning model.  
It comes with a ready-to-use **Streamlit app** — no need to retrain the model.

---

 🚀 How to Run Locally

 1️⃣ Clone this repository
```bash
git clone https://github.com/pavanimocharla/Naman-Digital-Internship2
cd house-price-predictor
2.Create and activate a virtual environment:
python -m venv .venv
.\.venv\Scripts\activate   # Windows
# or
source .venv/bin/activate  # Mac/Linux

3.Install Dependencies
pip install -r require.txt

4.Run the Flask App
streamlit run app.py

5.Open your browser and go to:
 Local URL: http://localhost:8501
  Network URL: http://192.168.1.39:8501
